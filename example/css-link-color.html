1. Как браузер выбирает цвет ссылки

Таблицы стилей
Браузер · каскад
Пояснения
Начало
Браузер вычисляет color для ссылки:
<nav class="nav">
  <a href="/docs">Документация</a>
</nav>
Стили браузера
Стандарт HTML задаёт цвет ссылок по умолчанию:
:link { color: #0000EE; }
:visited { color: #551A8B; }
Стили сайта
Автор страницы задаёт свои правила:
a { color: #333; }
.nav a { color: teal; }
Сбор объявлений
Отбирает объявления color, селекторы которых подходят ссылке: :link, a и .nav a.

:visited подходит только посещённой ссылке.

Шаг 1 · происхождение и важность
Обычные объявления сайта сильнее обычных объявлений браузера. :link выбывает.
Порядок происхождения · сверху сильнее
!important браузера
!important пользователя
!important сайта
обычные сайта
обычные пользователя
обычные браузера

Анимации и переходы в списке опущены.

Шаг 2 · специфичность
.nav a — (0,1,1), a — (0,0,1).

Контекст, атрибут style и слои @layer стоят между шагами 1 и 2. В примере они объявления не различают.

Шаг 3 · порядок в коде
Побеждает объявление, которое стоит позже.
Итог
Ссылка получает color: teal из .nav a.
Основание: HTML Standard, 15.3.4, CSS Cascade 5, порядок сортировки, Selectors 4, специфичность.

2. Атака: чтение истории через :visited

Атака
Скрипт задаёт посещённым ссылкам свой цвет и читает его, чтобы узнать, где был читатель:
a:visited { color: red; }

getComputedStyle(link).color
Защита браузера
getComputedStyle возвращает значение как для непосещённой ссылки.
Итог
Скрипт не отличает посещённую ссылку от непосещённой.
Только цвета
Для :visited браузер применяет color, background-color, border-color, outline-color и другие цветовые свойства. Прозрачность не применяется.
Итог
Размер и положение ссылки те же: по геометрии её не отличить.
Предел защиты
Цвет посещённой ссылки виден на экране. Ограничение скрывает его от скриптов, а не от читателя.
Основание: MDN, Privacy and :visited.
